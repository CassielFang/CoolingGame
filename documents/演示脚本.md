## 1. 开场（约 40 秒）

口播要点：

> 这是一款卡牌解谜侦探游戏，参考的是 Hillthorn 那套「全程无对白、信息全在卡牌里」的形态。
> 三个系统：**卡牌与行动**、**笔记本（线索页 / 问题页）**、**情节控制**。
> 今天演示的是最底下那层：**核心机制**——点卡出行动、配方判定、翻牌拿线索、五格结案，一整条推理线已经能跑通。

---

## 2. 主线演示（约 5 分钟 / 9 步）

| # | 操作 | 画面预期 | 讲什么 |
|---|---|---|---|
| 1 | 点 **「婴儿房」** | 底部弹出行动面板：`对「婴儿房」采取行动` + 金色「调查」 | 卡牌不预设行动，按钮是从**配方表反推**出来的 |
| 2 | 点 **「确认」** | 桌面多出一张**背面卡**，顶部提示「调查有了结果（新卡牌 1 张）」 | 新卡**背面朝上**，玩家得自己翻——这是信息节奏 |
| 3 | 点那张**背面卡** | 翻成「割断的绳索」，右上「笔记本 (1)」 | 翻牌即入档：卡牌自带线索 |
| 4 | 点 **「保姆 艾格尼丝」** → 「交谈」→「确认」 | 新卡「保姆的证词」背面；提示「新卡牌 1 张」 | 不同行动产不同结果；这一步同时置位一个隐藏 flag |
| 5 | 点开 **「保姆的证词」** | 笔记本 (2) | — |
| 6 | 点 **「温室」** → 「调查」→「确认」→ 点开新卡 | 得到「泥泞的靴子」 | 这条配方有**前置条件**（先听过保姆的话），没前置时按钮是灰的 |
| 7 | 点 **「走廊」** → 「前往」→「确认」 | 线索 +1（拖拽痕迹） | 「前往」是第三种行动，和调查/交谈同一套规则 |
| 8 | 点 **「割断的绳索」** | 面板变成「调查 **+1**」，出现一个**空卡槽** | 重点！同一张卡，卡槽里放不同的卡，结果不同 |
| 9 | 点 **「泥泞的靴子」**（自动入槽）→「确认」 | 提示新线索「泥土是同一种红土」 | **组合配方**：单看绳索只得到「潮气」，配上靴子才能比对泥土 |
| 10 | 点 **「园丁 托马斯」** → 「交谈」→「确认」 | 弹出情节演出《温室里的机油》→「继续」 | 情节节点由配方触发，看完才解锁后续 |

> 到这一步：8 张卡、6 条线索、行动 6 次，一整条推理链完整。

---

## 3. 笔记本（约 2 分钟）

1. 点右上 **「笔记本」**
2. **线索页**：
   - 6 条线索，每条带来源（「● 新线索」/ 来源卡名）
   - 点任意一条的 **「置顶」** → 它跳到最上面（讲：玩家可以自己整理线索板）
   - 在搜索框输入 **「温室」** → 列表实时过滤（讲：线索多了以后靠关键词检索）
3. 切 **「问题页」**：
   - 五个槽：案件 / 凶手 / 凶器 / 物证 / 人证
   - 点「凶手」行的 **「选择卡牌」** → 选 **「园丁 托马斯」**
   - 其余四槽同理填：婴儿房 / 割断的绳索 / 泥泞的靴子 / 保姆的证词
   - 点右下 **「结案」** → 提示「五格填满，真相吻合——破案。」
   - 讲：填满只是"完成"，**填对才是破案**；填错会得到"推理有误"

---

## 4. 失败反馈（30 秒，最能体现完成度）

- 点 **「保姆 艾格尼丝」** → 选 **「调查」** → **「确认」**
- 弹出「这样似乎行不通。」，面板**不关闭**，玩家可以立刻换行动重试
- 讲：失败分四种提示（无此配方 / 卡槽缺卡或放错 / 前置未解锁 / 时间不够），不会出现"点了没反应"

---

## 5. 收尾（约 30 秒）

> 整套规则只有一层：**卡牌 + 行动 + 附加卡 → 配方 → 新卡/线索/情节**。
> 加案件不用改代码：卡牌、线索、配方、答案都在一个 ScriptableObject 资产里配。
> 逻辑层是纯 C#、不含 Unity 依赖，目前 **26 个 EditMode 测试全绿**。
> 下一步：存档、时间压力、正式案件内容、美术替换。

## 6. 风险预案

| 情况 | 处理 |
|---|---|
| 面板挡视线 / 点错 | 点**空白桌面**任意处，面板关闭 |
| 状态乱了、顺序点错 | 右上 **「重新开始」**，30 秒内可以重跑全流程 |
| 演示时间被压缩 | 只演 第 1、2、3、8、9 步 + 笔记本结案（3 分钟版） |
| 现场卡住 | 切到 `documents/reference/demo/` 的六张截图继续讲，不要现场debug |
| 有人问"能不能不点鼠标" | 说明主控器留了 `Debug*` 接口，可以脚本驱动（已有自动化验证） |

## 7. 三分钟精简版（时间不够就用这个）

1. **婴儿房** → 调查 → 确认 → **翻牌**（讲：点卡出行动 + 翻牌拿线索）
2. **保姆** → 交谈 → 确认 → **翻牌**（讲：行动产出卡牌 / 隐藏前置）
3. **温室** → 调查 → 确认 → **翻牌**（讲：有前置条件才解锁）
4. **割断的绳索** → 点**泥泞的靴子**入槽 → 确认（讲：组合配方，同一张卡不同卡槽结果不同）
5. **笔记本** → 线索页搜索「温室」+ 置顶一条 → 问题页五槽 → **结案**（讲：线索管理 + 结案判定）

## 8. 可选：怎么顺手演示"时间压力"

资产 `Assets/Resources/Cases/SampleManorCase.asset` 里把 **Time Budget** 从 `-1` 改成 `10`，

（默认关闭，是刻意保持可调，方便按关卡节奏设计。）
